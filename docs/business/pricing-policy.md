# 오늘 네일 가격 정책 (내부 운영 문서)

## 1. 문서 목적
- 공개 페이지(`owner`, `user`)에서의 가격 노출 원칙과 내부 기준가를 명확히 관리한다.
- 외부 커뮤니케이션과 내부 수익화 준비 기준을 분리해 운영한다.

## 2. 공개 정책 (대외)
- 현재 공개 정책은 `완전 무료`다.
- 사장님 페이지와 사용자 페이지 모두 유료 플랜 가격을 노출하지 않는다.
- 공개 페이지에는 유료 전환 예고 문구를 사용하지 않는다.

## 3. 내부 기준가 (대내)
- 내부 기준가: `₩7,900 / 월 / 단일 플랜`
- 용도: 추후 수익화 시점 검토를 위한 내부 기준값
- 노출 원칙: 외부 페이지, 앱 화면, 마케팅 카피에 직접 노출 금지

## 4. 커뮤니케이션 원칙
- 사용자/샵 대상 메시지는 "현재 무료 제공" 중심으로 통일한다.
- 결제 정보 등록 유도 문구는 공개 페이지에서 사용하지 않는다.
- 가격/전환 관련 질문은 내부 정책 검토 후 별도 공지 채널에서만 다룬다.

## 5. 운영 점검 주기
- 점검 주기: 월 1회
- 점검 항목:
  - 도입 샵 수
  - 활성 샵 유지율
  - 운영 지원 비용(온보딩/문의 대응)

## 6. 변경 이력
- 2026-02-19: 최초 정책 문서 작성 (공개 무료, 내부 기준가 7,900원)
